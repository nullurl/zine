# Style Grammar

Use this skill for a white-field, monochrome editorial zine poster.

## Visual DNA

- Mostly blank paper, usually 75%-92% of the frame.
- One tiny grayscale anchor: photo fragment, object crop, diagram, clipping, or specimen.
- Black typography only unless the user explicitly requests color.
- Off-white, pale gray, or warm paper tone.
- Flat scan, photocopy wear, faint grain, soft registration drift.

## What To Extract From A Reference

- Paper tone and whitespace share.
- Anchor scale and placement.
- Text position, size, and hierarchy.
- Type voice: serif, sans, or typewriter.
- Reproduction feel: scan, xerox, offset, or print residue.
- Any numbering, date, or catalog logic.

## What To Avoid Copying

- Exact text, brands, logos, handles, or watermarks.
- Bright accents or scrapbook clutter.
- Commercial poster hierarchy.
- Clean UI framing or glossy studio lighting.

## Distinctive Rule

This skill should feel quieter and more conceptual than the source minimal-zine poster skill. Keep it near-monochrome and editorial, not color-led.
