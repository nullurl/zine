# Ink Gesture Poster Zine Style Grammar

Use this file when reverse-engineering the reference look or correcting drift.

## Reference Grammar

The target image language is an abstract ink gesture poster:

- tall vertical white paper field
- one central or slightly offset ink form
- long curves, loops, swishes, drips, or feathered trails
- black, gray, or charcoal motion with watery absorption
- one restrained accent such as red, cobalt, gold, or pale blue
- very large quiet margins around the gesture
- paper grain, scan noise, soft bleed, and faint speckling

The result should feel like a contemporary minimal print study, not a calligraphy sheet and not a traditional landscape.

## Minimal Zine Carryover

Use these from Minimal Zine:

- one attention anchor
- huge negative space
- matte paper surface
- sparse composition
- one clear accent
- editorial calm

## Gesture Anatomy

Always specify:

- one main ink core
- one motion path or trail
- optional orbit line, halo loop, or trailing filament
- one accent mark if useful
- paper surrounding the gesture on all sides

## Text Rules

- Use textless by default.
- If text is requested, keep it tiny and secondary.
- Do not copy reference signatures, letters, or watermarks.
- Do not add long copy, dates, URLs, or titles unless the user explicitly asks.

## Style Drift Corrections

If it becomes too painterly:

- say `abstract ink gesture poster, not a landscape or painting scene`

If it becomes too empty:

- say `one larger dominant ink gesture centered in the paper field`

If it becomes too busy:

- remove extra marks, extra accents, and extra type

If it becomes glossy or digital:

- add `matte paper, scan grain, feathered absorption, no 3D shine`

If the accent is lost:

- add `one small but vivid accent circle or splash`
