# Type Field System

## Layer Budget

Default:

- one primary display layer
- one expressive type layer
- one microtype layer
- zero or one serif/script contrast
- one ghost image
- zero to two diagram systems
- one signal color

Remove the contrast layer first when the page becomes crowded.

## Primary Display Layer

Carries title, event name, program name, or one key phrase. Use bold grotesk, condensed sans, or large serif. It should be the darkest or most legible text.

## Expressive Layer

Carries one emotional word or glyph band. Use handwritten script, stretched variable type, distorted modular letters, degraded bitmap type, or outline lettering. It can overlap the anchor but cannot destroy the primary title.

## Microtype Layer

Carries dates, venue, tracks, weights, months, locations, credits, or a short manifesto. Use mono or narrow grotesk. Keep text short and clustered in one band or column.

## Diagram Systems

### Orbit

One thin ellipse or path crossing the image anchor. Use 3-10 nodes maximum.

### Calendar

Months or dates arranged along a slow curve. Keep month labels sparse and avoid fake dense calendars.

### Route

Location names connected by one arc or fan. Use exact locations only when supplied.

### Specimen Table

Three to eight weight/style rows in mono text. Use only in Type Specimen Mode.

### Tracklist

Two short columns at the bottom. Use exact track names only when supplied.

## Opacity Ladder

- primary display: 70%-100%
- expressive layer: 35%-85%
- microtype: 40%-75%
- repeated ghost type: 8%-20%
- image anchor: 10%-35%
- diagram: 25%-60%
- signal mark: 80%-100%

This ladder prevents every layer from competing at full contrast.

## Alignment

Choose one dominant alignment:

- top-heavy stack
- bottom program band
- left specimen column
- vertical center label
- edge-to-edge title crossing a spectral subject

Do not use all alignments on one page.

## Copy Accuracy

- preserve user-supplied names, dates, venues, and titles verbatim
- do not invent real institutions, artists, sponsors, releases, or tour stops
- do not copy reference data
- reserve clean regions for later typesetting when exact long copy is required
