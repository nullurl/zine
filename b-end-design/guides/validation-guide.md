# Skill 验证脚本说明

## 使用方式

将以下指令发给 AI，让它自动验证生成的界面是否符合本 Skill 规范：

```
请对照 skill/rules/checklist.md，逐条检查以下代码是否符合 B 端设计规范：

[粘贴你的 HTML/CSS 代码]

输出格式：
- 通过项：列出符合规范的条目
- 问题项：列出不符合的条目，标注严重程度（严重/警告/建议）并说明修改方式
```

## 验证流程

1. 用 prompts/prototype.md 的人设生成界面原型
2. 将生成的代码粘贴到本脚本的指令中
3. AI 自动对照 checklist 逐条检查
4. 根据问题项修改 Skill 对应规范或修改代码
5. 重新生成，直到验证通过
