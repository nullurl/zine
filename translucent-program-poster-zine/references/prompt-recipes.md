# Translucent Program Poster Zine Prompt Recipes

Use this file when selecting layout, type hierarchy, or subject treatment.

## Recipe Matrix

### transparency-title-sheet

Use for: abstract phrases, transparency, memory, water, sky, or quiet poems.

Prompt ingredients:

- black outer field
- pale inner panel
- large translucent title across top or upper third
- ghost photo wash fading downward
- tiny bottom metadata line

### event-program-haze

Use for: events, festivals, talks, programs, or invented cultural listings.

Prompt ingredients:

- stacked ghost title lines
- tiny event metadata blocks
- one small photo rectangle
- faint vertical side information strip
- pale pink/blue/cream wash

### calendar-map-sheet

Use for: travel, time, seasons, routes, waiting, memory schedules.

Prompt ingredients:

- circular calendar numerals
- map or route lines
- one halftone landscape/photo panel
- month labels and tiny index text
- off-white sheets stacked with low contrast

### type-specimen-figure

Use for: design, typography, body, motion, shadow, figure studies.

Prompt ingredients:

- black side panel with mono type settings
- blurred white or gray human/object silhouette
- thin orbit scribble lines
- dense grain and monochrome palette

### album-tracklist-poster

Use for: music, album, playlist, film, chaptered story, cloud/sea/flight themes.

Prompt ingredients:

- large album or chapter title
- narrow film-strip band
- two small tracklist columns
- cloudy photographic wash
- month or edition label at bottom

### design-index-poster

Use for: visual design concepts, seeing, cognition, artificial memory, abstract systems.

Prompt ingredients:

- experimental glyph row
- blurred square image fragments
- tiny category list
- large date at bottom
- optional barcode-like decorative stripes, not scannable

## Theme Translation

For "transparency" or "fog":

- use pale panel, translucent type, blue-gray stains, and ghosted photo fragments.

For "time" or "calendar":

- use circular number paths, month labels, and one gray halftone photo panel.

For "music" or "album":

- use title, tracklist columns, image band, and atmospheric photo wash.

For "person" or "body":

- use blurred silhouette and type specimen side panel.

For "design" or "seeing":

- use glyph row, eye crop fragments, category list, and oversized date.

## Prompt Skeleton

```text
Portrait 3:5 raster image with a deep black outer field surrounding a smaller pale [fog white / gray-blue / cream] printed poster panel, flat scanned-paper lighting, visible paper fibers, low contrast, no glossy mockup.

Layout: [recipe]. Place [large translucent title / calendar diagram / side type panel / film-strip band] across [top / center / lower third], leaving controlled open space and one clear reading route.

Main anchor: [subject], rendered as [blurred halftone photo / soft silhouette / ghost diagram / faded image strip], partly dissolved into the paper with translucent ink, xerox grain, scan streaks, and slight misregistration.

Typography: title "[TITLE]" in [condensed grotesk / serif / mono / loose script], repeated ghost text at low opacity, two or three tiny fictional metadata zones, no long paragraphs, no real venues or sponsors.

Palette: [palette] with one restrained accent [optional], soft opacity overlaps, faded ink, old program-poster texture.

Avoid copied reference text, real brands, CTA, social flyer layout, UI, sharp stock photo, glossy 3D mockup, dense scrapbook, neon, and fake scannable codes.
```
