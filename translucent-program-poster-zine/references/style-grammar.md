# Translucent Program Poster Zine Style Grammar

Use this file when preserving the reference look or correcting style drift.

## Reference Grammar

The target language is a translucent printed program poster:

- deep black outer field or scan border around the poster
- central vertical paper panel, usually 70%-85% of the full image height
- foggy white, gray-blue, pale cream, or washed paper base
- oversized type laid over or behind image fragments at low opacity
- tiny metadata blocks placed like program, album, calendar, or design-spec information
- blurred photo elements: eye crops, figures, cloud fields, trees, film-strip bands, or abstract stains
- optional diagrams: circular calendar numbers, route map lines, node networks, thin orbit scribbles, side bars
- xerox grain, paper fibers, halftone noise, low contrast, soft misregistration, and faded ink

The composition should look scanned or photographed from a printed poster, not rendered as a digital UI.

## Minimal Zine Carryover

Use these from Minimal Zine:

- controlled paper field
- quiet emotional temperature
- old print and scan defects
- sparse attention route
- short text as visual matter
- restrained palette

The difference is scale: type and translucent photo layers may be much larger than Minimal Zine's usual tiny anchor.

## Poster Anatomy

Always specify:

- black outer field or wide black border
- inner pale poster panel
- one main type structure
- one main image/diagram structure
- two or three small metadata zones
- low-opacity overlaps and soft paper noise

## Text Rules

- Use exact user-supplied title, date, or phrase when provided.
- Otherwise invent short fictional title and metadata.
- Do not copy reference event names, venues, artists, sponsors, addresses, barcodes, or usernames.
- Keep metadata as texture; do not ask the image model for long readable paragraphs.

## Style Drift Corrections

If it becomes a clean event flyer:

- add `scanned archival poster, translucent ghost typography, no commercial flyer hierarchy`

If it loses the black border:

- add `deep black outer field surrounding a smaller pale poster panel`

If it becomes too blank:

- add `visible pale stains, ghost text, one soft image fragment, and tiny metadata zones`

If it becomes too sharp:

- add `soft blur, halftone degradation, xerox grain, low opacity ink`

If the result looks like UI:

- add `physical printed poster, not app interface, no website mockup`

If text copies references:

- replace with `fictional short non-identifying program text`
