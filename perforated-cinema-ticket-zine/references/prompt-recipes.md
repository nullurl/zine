# Prompt Recipes

Use one recipe per image. Keep the result within the ticket-card grammar.

## Recipe Fields

Before writing the final prompt, choose:

- Layout family
- Main title
- Chinese title placement
- Illustration subject
- Metadata block style
- Repeat strip usage
- Spot accent, if any

## Layout Families

### single-ticket

Use for one strong subject and a clean ticket object.

- One centered white ticket card.
- Large illustration in the upper half.
- Title at top, metadata below.
- Black background all around.

Prompt phrase:
`a single white perforated ticket card floating in a black void, with a bold title, a central printed illustration, and short ticket-style metadata rows`

### ticket-strip

Use for the most faithful reference look.

- One large main ticket.
- A narrow vertical strip of smaller repeated tickets on the right.
- Repeat strip can show the same design at smaller scale.
- Keep the main card dominant.

Prompt phrase:
`a main perforated cinema ticket card on the left and a narrow repeat strip of smaller tickets on the right, all floating in a black void`

### double-bill

Use for paired stories, two acts, or split themes.

- Two stacked cards or one card with two program sections.
- Each section should feel like a different feature.
- Keep the typography consistent across both sections.

Prompt phrase:
`two stacked perforated film-program ticket cards with shared black background and consistent monochrome typography`

### accent-card

Use for a controlled one-color variant.

- Keep the card mostly black and white.
- Add one accent field, burst, or title bar in red, yellow, pink, or cream.
- Make the accent visible at thumbnail size.

Prompt phrase:
`a monochrome perforated ticket poster with one bold spot-color accent on the title or illustration panel`

### poster-plus-stub

Use for a larger main card plus a smaller companion stub.

- Main card on one side.
- Smaller ticket stub or mini card beside it.
- The stub should echo the main image rather than introduce a new design.

Prompt phrase:
`a large perforated ticket poster with a smaller companion stub beside it, both on a black background`

## Typography System

- Main title: use the supplied title if short enough; otherwise invent a blunt, theatrical title.
- Chinese title: keep it short and integrated into the lower block or near the illustration.
- Genre line: optional and small, e.g. `Drama`, `Thriller`, `Romance`, `Sci-Fi`, `Mystery`.
- Metadata rows: optional ticket language such as `HALL`, `SEAT`, `PRICE`, `DATE`, `TIME`.
- Slogan line: optional bottom line, short and declarative.

## Prompt Skeleton

Use this structure:

```text
Vertical 4:5 poster, black void background, one dominant white perforated ticket card, die-cut scalloped edges, floating like a film program object, no mockup.

Main card: [illustration subject], [stage/still/object treatment], upper-half image panel, lower metadata block, repeat strip on the right if used, high-contrast print look.

Typography: bold [slab serif / distressed display / condensed serif] title reading "[short title]" at the top, short Chinese title, small genre line, ticket-like metadata rows, optional slogan, no paragraphs.

Palette: black-and-white base, [red / yellow / pink / cream] spot accent if needed, photocopy grain, halftone speckle, ink drag, worn edges, slight misregistration.

Mood: retro cinema, collectible program card, slightly uncanny, theatrical, hand-printed. Avoid glossy ad render, UI card, scrapbook clutter, neon, full-bleed scene, and cinematic 3D lighting.
```

## Variation Guidance

For multiple outputs, vary:

- title size
- repeat-strip presence
- accent color
- illustration subject
- metadata density

Keep the black void and perforated ticket grammar intact across all outputs.
