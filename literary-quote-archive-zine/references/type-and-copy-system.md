# Type and Copy System

## Copy Deck

Before generating, reduce the request to this deck:

```text
Index: 01
Section: LITERARY NOTES
Author: [exact user supplied name or ORIGINAL]
Title: [2-12 character/word title]
Quote: [1-4 short lines]
Highlight: [one exact phrase]
Attribution: [exact supplied attribution or omit]
Edition: [optional date/location]
Footer: [optional archive label and page number]
```

Never invent a real author's name or attach an unverified quote to one. If the user provides only a theme, use an original unattributed line or ask for copy before exacting a quote poster.

## Placement

- Index square: upper-left, 1%-3% of page width, accent fill.
- Section label: right of index square, tiny uppercase.
- Author: below header, dark serif, wide but not edge-to-edge.
- Outline title: overlaps author baseline or sits between author and quote.
- Quote: left column, 35%-55% page width, 3-7 lines.
- Highlight: one final line or phrase in accent.
- Attribution: below quote with a short rule.
- Image: lower-right/lower-center, never behind the whole quote.
- Footer: bottom margin with small label, page number, and thin rule.

## Scale

Use three type scales:

1. display name and outline keyword
2. quote block
3. archive microtype

Do not add a fourth headline, subtitle, slogan, and call-to-action. The quote is not marketing copy.

## Exact Text Rules

- Copy user text verbatim.
- Preserve punctuation and requested line breaks.
- Shorten only with explicit permission or when the user did not provide exact copy.
- Never use reference image text as filler.
- Image generation may distort type; keep the final composition easy to typeset later.

## Geometry Marks

Allowed support marks:

- one thin corner rule near top-left
- one quote mark
- one short horizontal attribution rule
- one dotted orbit or line path around the lower anchor
- one footer bracket or page index

Use no more than three support-mark families per poster.
