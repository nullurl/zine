# Travel Ticket Memory Zine Style Grammar

Use this file when a request asks to reverse-engineer a reference, preserve the card effect, or correct style drift.

## Reference Grammar

The target image language is a travel-memory ticket card:

- a vertical canvas with one large centered rounded card or a 3x3 grid of smaller cards
- a muted background color filling the full page
- the card is a single object with soft shadow and shallow relief
- the top 58%-70% is a rounded photo window
- the bottom 30%-42% is a solid ticket-stub information panel
- a semicircle notch is cut from the bottom center edge
- a row of tiny seam/perforation ticks may separate photo and panel
- the lower panel contains bold stacked place text, short date, `NO.` style index, and barcode-like stripes
- typography is compact, bold, sans, and sparse
- palettes are coordinated per card: sage, olive, dusty blue, taupe, smoke gray, warm clay, rose red, dark brown
- photo subjects are everyday memory fragments: trees, blossoms, roof tiles, fireworks, fish tanks, old walls, city glass, sunlight, rain, windows

The result should feel like a soft souvenir pass, archive ticket, or diary card, not a public transport ticket and not a phone UI.

## Minimal Zine Carryover

Use these from Minimal Zine:

- single strong visual system
- calm negative space around the card
- matte paper/card texture
- low-to-medium contrast
- restrained color logic
- sparse text as material, not a headline
- memory-like mood

The card may be larger than a minimal-zine anchor, but the page should still breathe. In a single-card layout, the surrounding background is the negative space.

## Card Anatomy

Always specify:

- rounded outer card corners
- top photo window with rounded top corners
- solid lower information panel
- visible semicircle bottom notch
- shallow contact shadow behind the card
- barcode-like decorative stripes in lower right
- place title in lower left
- date/index as small metadata

For grid layouts, each card keeps the same anatomy but color and photo subject can vary.

## Text Rules

- Use exact user-supplied title/place/date when provided.
- Otherwise invent short fictional labels.
- Do not copy reference labels like `GUI ZHOU` unless the user explicitly requests that exact text.
- Do not create real addresses, phone numbers, prices, QR codes, or scannable barcodes.
- Use fake short codes only as visual texture.

## Style Drift Corrections

If the output becomes UI:

- say "physical printed souvenir card, matte cardstock, not app UI"
- specify paper texture, shallow contact shadow, and die-cut notch

If the output loses the notch:

- say "large semicircle notch cut out from the bottom center edge, visibly interrupting the card edge"

If it becomes a transportation ticket:

- add "photo-window memory card, not train ticket, not boarding pass"

If it becomes too commercial:

- remove advertising words and CTA
- add "private diary archive, unbranded memory card"

If it copies reference text:

- replace with "fictional short title and fake non-identifying code"

If the card looks too flat:

- add "soft shadow, slight raised edge, paper thickness, matte cardstock grain"
