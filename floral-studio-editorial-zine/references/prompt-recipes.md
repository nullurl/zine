# Floral Studio Editorial Zine Prompt Recipes

Use this file when selecting a layout, title style, or color direction.

## Recipe Matrix

### single-specimen-sheet

Use for: one flower, fern, stem, petal, or butterfly-like mark.

Prompt ingredients:

- one tall paper sheet
- centered botanical anchor
- one compact type block
- ample empty field
- one ink color and one paper tone

### identity-block-poster

Use for: monograms, floral studio branding, initials, or logo-like posters.

Prompt ingredients:

- large initials or monogram as the primary form
- small botanical specimen or line drawing nearby
- short studio title in uppercase
- subtle scatter of dots, stamps, or registration marks

### blue-field-studio-sheet

Use for: the dusty sky-blue reference look.

Prompt ingredients:

- full-page cool blue background
- black botanical illustration or letterpress type
- soft paper grain and flat print light
- wide negative space

### ghost-press-page

Use for: pale, quiet, almost faded botanical sheets.

Prompt ingredients:

- off-white or paper-gray base
- faint specimen or nearly ghosted print
- black or charcoal type
- one or two tiny graphic marks

### two-panel-sheet

Use for: layouts that need both a title area and a specimen area.

Prompt ingredients:

- top type zone
- lower botanical zone
- strict separation by whitespace
- still sparse, not brochure-like

## Theme Translation

For a single bloom:

- use one stem or one pressed flower silhouette, paired with a short studio title

For a fern or tropical plant:

- use a single elegant leaf form and one pale blue or charcoal accent

For a butterfly or insect-like botanical mark:

- reduce it to a delicate printed specimen with soft edges and sparse type

For a brand or studio cue:

- use initials, a monogram, or a compact wordmark, but keep it fictional unless the user supplies exact copy

## Prompt Skeleton

```text
Portrait [3:4 / 4:5 / 3:5] raster image on a [cool ivory / dusty sky-blue / paper-gray] paper field, sparse botanical editorial composition, flat scanned-paper light, generous negative space, one dominant anchor placed [center / upper-right / lower-left].

One botanical specimen or monogram-led studio mark, rendered as [letterpress type / inked silhouette / ghost botanical print / dotted halftone], with antique print softness, slight misregistration, and a hand-pressed material feel.

Typography: short uppercase title "[TITLE]", compact typewriter or serif support text, one tiny studio line or edition note, no long copy, no real contact details, no logo campaign hierarchy.

Palette: [charcoal black / dusty sky blue / faded cobalt] as the main ink, with cool ivory or paper gray supporting the field; matte paper fibers, subtle scan noise, low-to-medium contrast, no glossy shine.

Avoid: scrapbook clutter, UI, commercial ad styling, neon, rainbow color, dense collage, product mockup, and copied reference text.
```
