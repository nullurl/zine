# Floral Studio Editorial Zine Style Grammar

Use this file when reverse-engineering the reference look or correcting drift.

## Reference Grammar

The target image language is a botanical editorial print sheet:

- tall vertical poster on cool off-white paper or dusty sky-blue paper
- huge empty field with one compact visual anchor
- antique typewriter or letterpress text in black or charcoal
- oversized initials, monogram fragments, or studio letters
- one botanical specimen, flower silhouette, or delicate plant mark
- occasional dotted margins, punch marks, or stamp-like black dots
- paper grain, scan softness, and slight misregistration

The result should feel like an independent floral studio sheet or botanical identity study, not a scrapbook page and not a commercial brand campaign.

## Minimal Zine Carryover

Use these from Minimal Zine:

- one visual system
- large negative space
- matte paper texture
- sparse text material
- archival calm
- a single dominant color or ink route

## Cardless Poster Anatomy

Always specify:

- one main botanical anchor
- one main text block or monogram cluster
- a quiet margin with air around the anchor
- paper fibers or print noise
- shallow, flat reproduction light

## Text Rules

- Use exact user-supplied title when provided.
- Otherwise invent short studio-like labels.
- Do not copy reference emails, names, or logos.
- Keep text short enough to read as a material layer, not a paragraph.
- Avoid real contact details, URLs, and sales copy.

## Style Drift Corrections

If the output becomes too modern:

- add `antique letterpress type, scanned paper, slight misregistration`

If it becomes scrapbook-like:

- remove stickers, tapes, ticket stubs, and layered ephemera

If it becomes a UI mockup:

- say `printed floral poster, not app interface, not dashboard`

If the anchor disappears:

- say `one centered botanical specimen or monogram, clearly the main object`

If the image becomes glossy:

- add `matte paper, flat light, print grain, no plastic shine`

If the palette drifts away from the reference:

- return to cool ivory, paper gray, black, charcoal, or dusty sky blue
