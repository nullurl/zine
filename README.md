## 💡 能力全景

### 什么是 Zine Skills？

Zine Skills 是一套面向 **电子手帐（Digital Journal）** 的 AI 图像生成技能集。每个 Skill 封装了一种独特的视觉风格基因——从稀疏编辑海报到植物剪贴簿、从电影票根到水墨纹身转印——通过自然语言一键生成高质量竖版手帐页面和视觉素材。

### 电子手帐的视觉语言

传统手帐依赖手绘、贴纸、胶带和照片打印。Zine Skills 将这一切数字化、AI 化：

| 手帐元素 | 对应 Zine Skill | 产出效果 |
|----------|----------------|----------|
| 🎨 **封面与标题页** | 终极编辑、分析诗学海报、花艺编辑 | 概念封面、论文式目录、极简标题卡 |
| 🖼 **摄影插页** | 日常叠影、柔焦记忆、余烬剪影、影像诗迹 | 生活摄影拼贴、旅行记忆、情绪氛围图 |
| ✂️ **拼贴与装饰** | 艺术废纸、绿色遐想、撕光档案、复印缺席 | 手工拼贴页、复古层次感、撕纸艺术 |
| 🏷 **标签与票根** | 电影票根、旅途票据、半透明节目单 | 电影/旅行纪念卡、演出票根风格 |
| 🌿 **自然与植物** | 植物剪贴簿、植物色谱、霓虹植物 | 花卉标本页、植物图鉴、夜间植物学笔记 |
| 📝 **文字与引用** | 文学语录、竖排诗条、光谱字体 | 名言页面、竖排诗歌、实验字体排印 |
| 🏛 **档案与记录** | 档案卷宗、纸本遗迹、地平线日记 | 旅行档案、研究记录、风景日志 |
| 🧵 **材质底纹** | 织物样本、牛皮纸编辑 | 面料质感背景、描图纸纹理 |
| 🖋 **东方美学** | 水墨笔势、水墨纹身、鎏金涟漪、风纱肖像、影荷拼合 | 水墨装饰、纹身风格插图、东方意境人物 |
| 🎭 **实验视觉** | 阈限仪式、光谱字体、纹身转印 | 先锋时尚内页、超现实舞台效果 |

### 手帐创作流

从一个主题到一本完整手帐的典型路径：

```
灵感/主题/记忆
    │
    ├→ 1. 封面 (终极编辑 / 分析诗学海报)
    ├→ 2. 目录与索引 (文学语录 / 半透明节目单)
    ├→ 3. 摄影内页 (柔焦记忆 / 日常叠影 / 余烬剪影)
    ├→ 4. 拼贴装饰 (绿色遐想 / 艺术废纸 / 撕光档案)
    ├→ 5. 标本图鉴 (植物剪贴簿 / 霓虹植物 / 植物色谱)
    ├→ 6. 旅行档案 (地平线日记 / 旅途票据 / 档案卷宗)
    ├→ 7. 诗意文字 (竖排诗条 / 影像诗迹 / 光谱字体)
    ├→ 8. 东方装饰 (水墨笔势 / 鎏金涟漪 / 纹身转印)
    ├→ 9. 票据收藏 (电影票根 / 旅途票据)
    └→ 10. 封底与背景 (织物样本 / 牛皮纸编辑 / 纸本遗迹)
```

### 与 AI 手帐工具协同

这些 Skill 产出的竖版图像天然适配主流电子手帐场景：

- **GoodNotes / Notability**：直接插入为手帐内页或装饰元素
- **Notion / Obsidian**：作为日记封面、卡片头图、视觉引用
- **小红书 / 朋友圈**：独立成图的日常手帐分享
- **Canva / Keynote**：作为排版素材，二次叠加文字和贴纸
- **打印输出**：高分辨率 3:4/2:3 比例，适合实体手帐本打印

## 🏗 结构

每个 Skill 目录遵循统一结构：

```
<skill-name>/
├── SKILL.md          # 技能核心文件（提示词编译器、布局引擎、质量控制）
├── agents/            # AI Agent 配置
├── references/        # 风格语法、提示词配方、参考系统
│   ├── style-grammar.md
│   └── prompt-recipes.md
├── scripts/           # 图像生成脚本
│   └── server_image_gen.py
└── output/            # 生成输出（提示词记录、成品图）
```

## 🚀 使用说明

### 环境要求

- 支持 **SKILL.md** 规范的 AI 助手（Cindy / Codex / Claude Code / Pi 等）
- 已配置图像生成能力的 AI 模型（如 GPT Image、DALL·E 等）
- Python 3.11+（用于 `server_image_gen.py` 本地备选生成）

### 安装与导入

**方式一：直接导入目录**

```bash
# 克隆仓库
git clone https://github.com/nullurl/zine.git

# 将需要的 Skill 目录复制到 AI 助手的 skills 目录
cp -r zine/<skill-name>/ ~/.agents/skills/<skill-name>/
```

**方式二：从小红书 SkillHub 获取**

在小红书 App 中搜索 "Zine Skills"，选择需要的技能添加到你的 AI 助手。

### 基础使用

```
# 步骤 1：在对话中 @ 触发技能
@analytical-skyline-poetry-zine 帮我做一张关于"城市天际线"的海报

# 步骤 2：提供更多细节
用蓝色作为强调色，加入一句中文诗句

# 步骤 3：AI 自动生成
AI 会编译专业图像提示词并调用生图能力输出成品
```

### 集成到工作流

#### GoodNotes / Notability

```
1. 用 Zine Skill 生成竖版手帐内页
2. 保存为 PNG
3. 拖入 GoodNotes 作为新页面
4. 在上面自由书写、添加贴纸
```

#### Notion / Obsidian

```
1. 生成封面图 → 设为笔记头图
2. 生成装饰元素 → 嵌入日记卡片
3. 生成票根风格图 → 作为旅行日记插图
```

#### 小红书 / 朋友圈

```
1. 生成独立成品图
2. 直接发布，无需二次排版
3. 3:4 比例适配竖版内容流
```

#### 实体手帐打印

```
1. 选择 2:3 或 3:4 比例 Skill
2. 生成高质量 PNG（1024x1536+）
3. 按手帐本尺寸缩放打印
4. 贴上实体胶带、印章完成混合手帐
```

### 常见问题

**Q: 生成的图片风格不对怎么办？**
A: 在提示中加入「参考图」或明确指定布局族。每个 Skill 的 SKILL.md 中有详细的 Layout Engine 指引。

**Q: 如何切换色彩方案？**
A: 在提示中指定色彩名称（如「使用深海蓝」）或直接给出色号（如「强调色 #0F2E48」）。

**Q: 生成失败怎么办？**
A: 确认 AI 助手已配置图像生成模型。备选方案：使用 `scripts/server_image_gen.py` 本地调用 OpenAI 兼容 API。

**Q: 可以商用吗？**
A: 参见下方「原创声明」章节。

- **布局引擎（Layout Engine）**：每个 Skill 包含 4-6 种原创布局族，定义了独特的空间节奏和视觉语法
- **风格语法（Style Grammar）**：从零建立的视觉 DNA 系统，包括纸张场域、锚点尺度、字体层级、质感缺陷和扫描美学
- **提示词编译器（Prompt Compiler）**：自主设计的 4-6 段式提示词结构，将抽象主题翻译为精确的图像描述
- **色彩趋势引擎（Color Trend）**：10 套原创配色方案，每套包含 5 色色板和情景映射规则
- **融合逻辑**：所有 Skill 共享一套 Minimal Zine 设计基因，通过各自的几何变形规则派生差异化风格
