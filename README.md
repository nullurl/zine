# Zine Skills

35 个 AI 图片生成技能（Skill），覆盖海报、编辑册、拼贴、纹身、织物、档案等多种 zine 风格。每个 Skill 通过自然语言提示词驱动图像生成模型，产出高质量竖版 zine 图像。

## 🏗 结构

每个 Skill 目录遵循统一结构：

```
<skill-name>/
├── SKILL.md          # 技能核心文件（提示词编译器、布局引擎、质量控制）
├── agents/            # AI Agent 配置
├── references/        # 风格语法、提示词配方、参考系统
│   ├── style-grammar.md
│   └── prompt-recipes.md
├── scripts/           # 图像生成脚本
│   └── server_image_gen.py
└── output/            # 生成输出（提示词记录、成品图）
```

## 🚀 使用方式

1. 将 Skill 目录导入支持 SKILL.md 的 AI 助手（如 Cindy、Codex、Claude Code）
2. 对话中 `@skill-name` 触发对应技能
3. 提供主题、关键词、参考图或一句话描述
4. AI 自动生成专业图像提示词并输出成品图
