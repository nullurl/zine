# Gathered Memory Collage Zine

## Overview

Turn an ordinary subject into a small layered collage on a wide field of paper. Keep the gc-minimal-zine-poster-v0-1 discipline, but shift the result toward tactile memory-board materials: torn photos, translucent overlays, soft shadows, and one quiet focal cluster.

## Core Rules

- Keep the page mostly empty. Aim for 70%-90% paper.
- Make one main collage cluster, usually near center or lower-middle.
- Use 1-3 photo scraps, not a full scene.
- Prefer warm ivory, oatmeal, cream, faded gray, muted blue, soft green, and dusty peach.
- Let tape, vellum, graph paper, perforation holes, and deckled edges stay visible.
- Keep captions tiny, sparse, and archival.
- Borrow structure from gc-minimal-zine-poster-v0-1, but make the surface feel layered and collected, not poster-clean.

## Workflow

1. Read the source.
   - If an image is supplied, preserve its core subject, angle, and emotional temperature.
   - If only text is supplied, choose one everyday memory fragment that can be photographed: fruit, flower, meal, shoreline, window view, child, pet, travel view, or small object.

2. Choose one layout family from the reference file.
   - Prefer centered stacks for calm subjects.
   - Prefer offset stacks for travel or documentary subjects.
   - Prefer paired scraps when the source has a strong main scene and one supporting detail.

3. Compile a prompt in four paragraphs.
   - Canvas and paper.
   - Memory anchor.
   - Marks and typography.
   - Mood and avoids.

4. Generate the image.
   - Keep the collage flat and scanned, not like a 3D mockup.
   - If the page feels too busy, remove elements before adding more.
   - If the subject becomes too tiny, enlarge the main scrap before adding extra decoration.

5. Return the image, final prompt, and the chosen recipe.

## Prompt Shape

Use short, imageable instructions.

**Canvas and paper**
- State ratio, paper tone, texture, and how much of the page stays empty.

**Memory anchor**
- State the main subject, number of scraps, crop shape, placement, and tape or vellum treatment.

**Marks and typography**
- State orbit lines, dotted paths, tiny x-marks, rules, archive labels, or poetic captions.

**Mood and avoids**
- State the emotional register and the hard no list.
